# Scropper (Scroll Stopper)

Android zero-distraction YouTube + Instagram client. Kotlin (Compose + dual WebView) + Rust core over JNI.

## Layout
- `rust-core/` — Rust `cdylib` (`scropper_core`): URL blocker, Shorts URL rewriter, CSS/JS injection payload, JNI exports. Logic in `src/lib.rs`, JS template in `src/inject.js`, ad blocking (Brave `adblock` engine) in `src/ads.rs`.
- `android/` — Gradle project, package `com.scropper.app` (minSdk 26, targetSdk 35). Sources in `app/src/main/java/com/scropper/app/`.
- `android/app/src/main/assets/adblock/` — bundled uBlock Origin filter lists (large: never read whole, grep only) and `resources.json` (uBlock Origin scriptlets, generated by `scripts/gen_adblock_resources.py`; do not hand-edit).
- `.toolchain/` — isolated local toolchains: JDK, Android SDK + NDK, rustup, cargo, Gradle home, `bin/rtk`. Configured by `./env.sh` (sets `JAVA_HOME`, `ANDROID_HOME`, `ANDROID_NDK_HOME`, `RUSTUP_HOME`, `CARGO_HOME`, `GRADLE_USER_HOME`, `PATH`).

## Rules (critical)
- EVERY Bash command using cargo, rustup, gradle, gradlew, sdkmanager, adb: prefix with `source ./env.sh && ` (use the path to `env.sh` relative to cwd, e.g. `source ../env.sh && ` inside `rust-core/` or `android/`).
- NEVER read, grep, list, or inspect `.toolchain/`, `target/`, `build/`, `.gradle/`.
- Read files partially: use Read `offset`/`limit` for anything large; grep for the symbol first, then read only that range. Do not re-read files just edited.
- `android/app/src/main/jniLibs/` is generated by the Gradle `cargoNdkBuild` task. Do not edit or commit.

## Commands
```bash
# Rust unit tests
cd rust-core && source ../env.sh && cargo test

# Debug APK (runs cargo-ndk for arm64-v8a first, then Gradle)
cd android && source ../env.sh && ./gradlew assembleDebug
# -> android/app/build/outputs/apk/debug/app-debug.apk

# Refresh bundled ad filters (the app also updates the lists itself, daily)
# lists: download into android/app/src/main/assets/adblock/ (URLs in AdBlock.kt)
# scriptlets: copy uBlock's src/js/resources/*.js + src/js/{jsonpath,arglist-parser,urlskip}.js into one dir, then
python3 scripts/gen_adblock_resources.py <that dir> android/app/src/main/assets/adblock/resources.json

# Install on device
cd android && source ../env.sh && adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## JNI contract
Kotlin `com.scropper.app.RustCore` (static externals) <-> Rust `Java_com_scropper_app_RustCore_*`:
- `shouldBlockUrl(url, host, blockYtShorts, blockIgReels, blockIgExplore): Boolean`
- `rewriteNavigationUrl(url): String?` (null = no rewrite)
- `getInjectionScript(site, blockYtShorts, blockIgReels, blockIgExplore, blockAds): String` (`site` = `youtube` | `instagram`)
- `adblockLoadLists(trustedLists, untrustedLists, resourcesJson): ByteArray?` (UTF-8 bytes in, serialized engine out)
- `adblockLoadCache(serialized, resourcesJson): Boolean`
- `adblockShouldBlock(url, sourceUrl, requestType, method): Boolean`
- `adblockCosmeticScript(url): String`

Renaming package, class, or method on either side breaks linking at runtime, not at build time.
